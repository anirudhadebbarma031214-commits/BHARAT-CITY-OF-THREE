# BHARAT: CITY OF THREE — Unity restart

The project is being restarted as a **Unity 6 Windows PC project**. The old Godot prototype is removed from the current branch tree; its Git history remains available.

## First playable prototype
The initial scene is generated by the Unity Editor build script and includes a procedural Northeast India-inspired street block, road markings, shops, trees, a pond, a simple auto-rickshaw, third-person movement and a basic HUD. These are placeholder procedural assets, not final realistic AAA assets.

## Open locally
1. Install Unity Hub: https://unity.com/download
2. Install Unity Editor **6000.0.38f1** with Windows Build Support.
3. Clone this repository and open the folder in Unity Hub.
4. In the Unity menu choose **BHARAT → Build Windows EXE** to generate `Build/BHARAT-CITY-OF-THREE.exe`.

## GitHub Actions build
The workflow uses GameCI and requires a valid Unity license secret. Configure `UNITY_LICENSE` in repository Actions secrets; if your license setup requires them, also configure `UNITY_EMAIL` and `UNITY_PASSWORD`. Then run **Actions → Unity Windows Build → Run workflow**. See https://game.ci/docs/github/getting-started/.

## Important
This is a starter prototype, not a finished 50 GB game and not GTA-level graphics yet. Realistic city assets, animation, driving, missions, traffic AI, audio and optimization must be added and tested iteratively.
